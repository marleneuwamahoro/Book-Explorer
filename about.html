About Book Explorer 📚

Book Explorer is a responsive web application built using HTML, Tailwind CSS, and JavaScript. Users can search books using a public API, save favorites, and explore books dynamically.

Features

  • ✅ Search books from API
  • ✅ Responsive design
  • ✅ Favorites system
  • ✅ localStorage persistence
  • ✅ Mobile navigation

Technologies

  • HTML5
  • Tailwind CSS
  • JavaScript ES6
  • Fetch API
  • Open Library API
